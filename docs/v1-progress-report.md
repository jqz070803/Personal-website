## v1 · 本次迭代（MVP）

### 🎯 版本目标
- 完成一个**大气、简约、以"山川湖海"为主题**的个人网页主页。
- 适用于三类场景：简历/面试给 HR、陌生初次见面介绍自己、老师/朋友浏览。
- 桌面端与手机端均能正确显示（响应式）。
- 为后续迭代预留结构：**智能体（Agent）位置**。

### 🎨 视觉设计感升级（第 2 轮）
- **首屏背景**：由纯色/单一渐变，加入**星空微光 + 层叠山峦剪影**矢量背景，
  贴合"山川湖海"主题，打破纯色、更有场景层次感；文字保持聚焦，不影响可读性。
- **"关于我"区块重构**（下滑第一个区块）：改为 **左个人照片 / 右个人信息 + 科研获奖成果** 左右布局。
  - 左：照片帧（占位，待替换真实照片），含说明"江沁钊 · 行走于山川湖海"。
  - 右：`一处坐标`、`一个灵魂` 信息卡 + `科研 · 获奖成果` 卡（目前为空位占位，待逐步补充）。
  - 手机端自动转为上下堆叠，照片居中。
- 桌面端 / 移动端截图均已重新验证通过。

### 🌌 整体深色主题 + 滚动动效升级（第 3 轮）
- **整站改深色夜景基调**：去除"深色 hero → 突然跳浅色"的生硬切换，全页统一为深空蓝黑基调，
  文字、卡片、导航、分区全部适配，背景连贯流畅（`--paper` / `--card` 等变量重写为深色）。
- **滚动背景色渐变**：随鼠标下滑，页面背景在 5 档深空色带之间缓慢、平滑地流动
  （含非线性缓动），背景颜色不会生硬跳变，贴合"穿越山海"的沉浸感。
- **模块滑动入场动画**：各区块/卡片支持上浮、左右滑入与**交错延迟**入场
  （`data-dir` / `data-stagger`），下滑时内容依次错落浮现；包含 `.reveal` 增强。
- 移动端汉堡菜单、分隔线等一并适配深色主题。
- 桌面端 / 移动端截图均已重新验证通过。

### 🔄 本轮视觉升级（Apple 官网风）
根据反馈：**去掉左上角品牌名、去除"土气感"，转向 Apple 官网式极简高级**。
- **导航**：改为居中对齐、透明背景（滚动后毛玻璃），移除左上角名字与 CTA 按钮。
- **配色**：去掉花哨的金色渐变，改用冷峻深邃的深空蓝 + 白色 + Apple 系蓝（`#0a84ff`）的点缀，
  页面底色为大面积白色留白 + 浅灰（`#f5f5f7`）分区。
- **字体**：统一现代无衬线（SF Pro / PingFang），标题大号、克制字重、收紧字距（letter-spacing -0.02em）。
- **图标**：镜头区改用简洁的线性 SVG 图标（相机 / 无人机 / 播放器），去除 emoji。
- **光影**：卡片使用轻阴影 + 更柔和的 hover，hero 夜景加深渐晕让文字更聚焦。
- 桌面端与移动端截图均已重新验证通过。

### 📱 技术要点
- **纯前端静态实现**：`HTML + CSS + JS`，无外部框架依赖，无需构建即可打开，稳定且易于后期扩展。
- **响应式设计**：桌面（≥760px 多列网格）与手机（<760px 单列堆叠 + 汉堡菜单）自适应。
- **滚动显现动效**、**数字滚动统计**、**导航滚动变色**、**移动端汉堡菜单**等交互动效。
- **截图/预览模式**：URL 加 `?shot=1` 可即时显示全部区块，便于截图与打印。
